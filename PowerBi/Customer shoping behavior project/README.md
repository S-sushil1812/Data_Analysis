##📊 Customer Behavior Analysis Dashboard
📌 Project Overview

This project is an interactive Customer Behavior Analysis Dashboard developed using Python, SQL, PostgreSQL, and Power BI. The project focuses on analyzing customer purchasing patterns, subscription behavior, repeat buyers, and revenue trends using customer shopping data.

The main goal of this project is to transform raw customer data into meaningful business insights through data cleaning, SQL analysis, and dashboard visualization.

🚀 Features
📈 Customer Purchasing Behavior Analysis
👥 Subscriber vs Non-Subscriber Analysis
💰 Revenue Analysis by Category
🛍️ Top Purchased Products Analysis
🔄 Repeat Buyer Analysis
📊 Age Group Revenue Contribution
⭐ Product Review Rating Analysis
🎨 Interactive Power BI Dashboard
🧹 Data Cleaning & Preprocessing using Python
🗄️ PostgreSQL Database Integration
