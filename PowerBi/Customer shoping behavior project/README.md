Customer Behavior Analysis
Project Overview

The Customer Behavior Analysis project focuses on analyzing customer shopping patterns and purchasing behavior using data analytics techniques. The project uses Python for data preprocessing, PostgreSQL & SQL for data analysis, and Power BI for interactive dashboard visualization.

The main objective of the project is to identify customer trends, subscription behavior, repeat buyers, revenue contribution, and customer preferences to generate meaningful business insights.

Objectives
Analyze customer purchasing behavior
Identify repeat buyers
Study subscription patterns
Find revenue contribution by age group
Understand customer preferences
